# Ledger de entregas geradas

Esta branch NAO e a main e NAO define o codigo instalado. Registros em entregas/<ID>.json sao imutaveis e descrevem propostas. Para codigo atual, consulte main e fixe seu SHA. Para regra completa de hashes/observacoes/testes, leia RASTREABILIDADE.md na main.

Arquivos desta branch podem ser escritos pela IA somente com autorizacao/confirmacao das ferramentas. Nao modificar main nem substituir registros antigos. Se um registro estiver incorreto, crie outra entrega/ID com relacao explicita.
